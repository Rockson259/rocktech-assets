# RockTech — public social assets

Rendered images and video for RockTech Software Solutions' social media, hosted
publicly so that Buffer can fetch them when scheduling a post.

**This repository is public on purpose, and holds nothing that was not already
going out.** Every file here is a finished asset intended for Instagram,
Facebook and LinkedIn.

**What is deliberately NOT here:** captions, the content calendar, pricing, the
client register, strategy documents, and anything else from the private
operations repository. No client is named in any asset. Source files, brand
originals and the generating code stay private.

Assets are rendered from `tools/make-social.py` and the Remotion project in
`reels/`, both in the private repo. **Do not edit anything here by hand** — it
is build output and will be overwritten.

## Sizes

| Suffix | Dimensions | Renders uncropped on |
|---|---|---|
| `-4x5.png` | 1080×1350 | Instagram, Facebook, LinkedIn, Threads |
| `-1x1.png` | 1080×1080 | X, Instagram profile grid |
| `.mp4` | 1080×1920 | Reels, Stories, TikTok, Shorts |
